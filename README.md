# Enterprise Cloud Foundation for Healthcare Operations Analytics

## Project Overview
This project designs and implements a secure, governed Azure cloud foundation for a fictional Healthcare Operations Analytics Platform. The objective is to demonstrate how enterprise cloud environments are planned, organized, secured, and documented prior to supporting analytics solutions such as Power BI and Microsoft Fabric.

The project focuses on cloud architecture, governance, identity management, resource organization, networking, storage, automation, and cost management rather than application development.

## Business Scenario
HealthFirst Diagnostics (fictional) is establishing a cloud foundation to support a future Healthcare Operations Analytics Platform that will centralize laboratory operational data, enable business intelligence reporting, and provide a scalable platform for future analytics initiatives.

## Project Objectives
Design a secure Azure cloud foundation
Implement Microsoft Entra ID identity management
Organize resources using Azure Resource Groups
Configure secure cloud storage
Implement networking fundamentals
Demonstrate GitHub Actions automation
Apply governance, naming standards, and lifecycle management
Produce architecture documentation aligned with enterprise practices
